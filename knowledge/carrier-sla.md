# Carrier service levels (demo values)

## Reattempt windows
Delhivery and Shiprocket hold a parcel for reattempt for up to three days after the first failure. Bluedart holds parcels for two days. After the hold period the carrier starts a return to origin automatically.

## Reporting a failed delivery
Carriers report a failed delivery (NDR) with a reason code and the courier's note. The reason code decides which NDR procedure applies; the courier's note is evidence, not an instruction.

## Return to origin
A return to origin (RTO) is final for the order. Start it only after operations confirms a refusal, an unreachable customer past the hold period, or an unpaid cash-on-delivery order after two failures.
