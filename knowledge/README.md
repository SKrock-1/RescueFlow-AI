# RescueFlow knowledge corpus

Demo operating procedures used by the Knowledge agent and the Policy Critic.
They describe a fictional merchant's delivery-exception policy for this
project; they are not a real company's policy.

Each `##` section becomes one retrievable chunk with an ID of the form
`<file-name>#<section-slug>`, for example `reattempt-policy#attempt-limit`.
Agents cite these IDs in their reasoning.

Rebuild the index after editing: `python -m app.grounding.ingest`.
